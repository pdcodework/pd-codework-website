# PD CODEWORK — Digital Solutions

> **Official Website for PD CODEWORK**  
> *Build Better. Grow Faster with Digital Solutions.*

A modern, fast, fully responsive, and SEO-optimized static business website designed for **PD CODEWORK**, providing professional web development, web applications, AI automation, API integrations, and custom software solutions.

---

## 🚀 Live Demo & Getting Started

This website is built entirely with vanilla web standards and requires **no build tools, no Node.js runtime, no backend, and no database setup**.

### Quick Run:
1. Double-click or open `index.html` in any web browser (Google Chrome, Edge, Safari, Firefox).
2. Alternatively, run a lightweight local server:
   ```bash
   # Python 3
   python -m http.server 3000

   # Or with VS Code Live Server extension
   ```

## ⚙️ Customization Guide

### Updating Contact Information:
Open `index.html` and edit lines in the `#contact` and `footer` sections:
- **Email**: Replace `hello@yourdomain.com` with your real email.
- **Phone**: Replace `+91 XXXXX XXXXX` with your business phone number.
- **Socials**: Update the `href` values for Instagram, LinkedIn, and GitHub.

### Deploying to Free Static Hosts:
- **GitHub Pages**: Push this repository to GitHub and enable GitHub Pages under repository settings (`main` branch -> `/root`).
- **Netlify / Vercel / Cloudflare Pages**: Drag and drop the folder directly onto your dashboard for instant global CDN deployment.
